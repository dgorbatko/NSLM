# Contributing to NSLM

Thank you for helping improve NSLM.

## Reporting a bug

Open a GitHub issue and include:

- NSLM version and Windows version;
- the game folder type and the relevant scan or update steps;
- the expected and actual result; and
- the relevant part of `%LOCALAPPDATA%\NSLM\error.log`, with account names, local paths, and API keys removed.

Do not attach Steam account credentials, SteamGridDB API keys, game files, or copyrighted artwork.

## Suggesting a feature

Explain the problem first, then describe the workflow that would solve it. Screenshots are welcome when they do not expose personal information.

## Pull requests

Keep changes focused, include tests when practical, and do not commit build output, local NSLM data, cached artwork, Steam configuration, or API keys.
